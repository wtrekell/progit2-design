# Icons

SVG icons for navigation and actions throughout the application.

## Icon Set

### Navigation
- `home.svg` — Dashboard
- `sketch.svg` — Sketch input
- `generate.svg` — Generation / processing
- `compare.svg` — Results comparison
- `refine.svg` — Refinement editor
- `export.svg` — Export
- `history.svg` — Version history
- `settings.svg` — Settings

### Actions
- `upload.svg` — Upload file
- `draw.svg` — Freehand draw mode
- `import.svg` — Import from external tool
- `regenerate.svg` — Regenerate option
- `select.svg` — Select / confirm
- `overlay.svg` — Overlay comparison mode
- `download.svg` — Download export

### Status
- `check.svg` — Success / pass
- `warning.svg` — Warning
- `error.svg` — Error / fail
- `info.svg` — Information

## Conventions

- Base grid: 24x24px
- Stroke width: 1.5px
- Corner radius: 1px on stroke ends
- Color: currentColor (inherits from parent)
- Format: Optimized SVG (no embedded styles, no IDs)
