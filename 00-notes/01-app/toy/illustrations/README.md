# Illustrations

Custom illustrations for onboarding, marketing, and in-app guidance.

## Categories

### Onboarding
Illustrations for the 3-step first-run experience:
- Step 1: Upload a sketch (hand drawing a wireframe)
- Step 2: See options generated (5 cards fanning out)
- Step 3: Refine and export (polished screen with export arrow)

### Marketing
Hero images and feature illustrations for the landing page and documentation.

### In-App
Empty states, error states, and success confirmations.

## Conventions

- Style: Clean line art with brand color accents (primary #2563EB, secondary #7C3AED)
- Export: PNG at 800px width for standard, 1600px for retina
- Naming: `{category}-{description}.png` (e.g., `onboarding-upload-sketch.png`)
