# SketchSpark — Competitive Analysis

## Market Overview

The AI-assisted design tool market is growing rapidly, but no existing tool combines sketch-based input with parallel option generation and design token integration. Most competitors focus on text-to-UI or general image generation.

---

## Direct Competitors

### Uizard

**What it does**: Generates UI screens from text descriptions and hand-drawn sketches.

**Strengths**:
- Supports sketch-to-UI conversion
- Collaborative workspace
- Component library included

**Weaknesses**:
- Single output per generation (no parallel options)
- Limited design token support
- Accessibility checking not integrated
- Output quality inconsistent for complex layouts

**SketchSpark advantage**: Parallel option generation, design token enforcement, accessibility by default.

---

### Galileo AI

**What it does**: Generates high-fidelity UI designs from text descriptions.

**Strengths**:
- High visual quality output
- Natural language input
- Figma integration

**Weaknesses**:
- Text-only input — no sketch interpretation
- Single output per prompt
- No design token integration
- Limited platform awareness (primarily web)

**SketchSpark advantage**: Sketch-based input preserves spatial intent, 5 parallel options, multi-platform generation.

---

### Framer AI

**What it does**: Generates and publishes websites with AI assistance.

**Strengths**:
- End-to-end: design to published site
- Good visual quality
- Real responsive output

**Weaknesses**:
- Web-only (no native mobile)
- Focused on shipping, not exploration
- No sketch input
- Limited to Framer's component system

**SketchSpark advantage**: Exploration-focused, multi-platform, sketch input, design token integration.

---

## Adjacent Competitors

### Figma (with AI features)

**Relationship**: Figma is a canvas tool, not a generator. SketchSpark exports *to* Figma. They are complementary, not competitive. Figma's emerging AI features (auto-layout suggestions, content generation) operate within existing designs rather than generating new ones from sketches.

### Midjourney / DALL-E

**Relationship**: General image generators produce visual inspiration but not structured UI. Output is a flat image — no layers, no components, no tokens, no accessibility, no code export. Useful for mood boards, not for production design work.

## Key Insight

No competitor offers parallel option generation from sketch input with design token constraints. This combination — spatial intent preservation + multi-direction exploration + brand consistency — is SketchSpark's core differentiator and the gap we are building into.
